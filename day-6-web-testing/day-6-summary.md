# Day 6 Summary

## Authentication vs Authorization

Authentication verifies the identity of a user. It answers the question: "Who is the user?"

Authorization determines what an authenticated user is allowed to access or perform. It answers the question: "What is this user allowed to do?"

A system can correctly authenticate a user but still have an authorization vulnerability if it allows that user to access functions or resources they should not be permitted to use.

## Vulnerability vs Exploit vs Impact

A vulnerability is a weakness or flaw in a system that could be abused.

An exploit is the method or technique used to take advantage of a vulnerability.

Impact describes the consequence of successfully exploiting the vulnerability, such as unauthorized access, data exposure, or unauthorized actions.

The three concepts are related but different. A vulnerability identifies the weakness, an exploit demonstrates how the weakness can be used, and impact explains what could happen as a result.
