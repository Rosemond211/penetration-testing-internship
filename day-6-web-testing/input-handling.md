# Input Handling Lab

## Objective
Test an input-handling weakness in an authorized PortSwigger Web Security Academy training lab.

## Observation
The application accepted user-controlled input through an input field or request parameter.

## Hypothesis
The application may not properly validate or encode user-supplied input before processing or displaying it.

## Test
I tested the handling of user-controlled input within the authorized training environment.

## Evidence
The training lab demonstrated the security impact of insufficient input validation or output handling.

## Result
The lab confirmed that improperly handled user input can create a web application security vulnerability.

## Lesson Learned
User-controlled input should be validated and safely handled before being processed or returned by an application.
