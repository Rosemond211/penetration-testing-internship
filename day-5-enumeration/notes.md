# Day 5 - Web Enumeration with Free Tools
## Target

PortSwigger Web Security Academy training environment.
## Authorization / Scope
Testing is limited to the PortSwigger-provided training environment. No public or third-party systems are being tested.

## Objective
Inspect HTTP requests and responses, identify useful information such as status codes, headers, cookies and parameters, and practice safe web enumeration using browser DevTools, Burp Suite Community Edition and curl.

## Tools
- PortSwigger Web Security Academy
- Burp Suite Community Edition
- Browser Developer Tools
- curl
